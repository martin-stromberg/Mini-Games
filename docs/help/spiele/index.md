# Wortsuchrätsel

Das Wortsuchrätsel hilft beim Üben englischer Vokabeln. Im Buchstabengitter sind zehn englische Wörter versteckt; die deutschen Übersetzungen stehen daneben. Du findest die Wörter, indem du ihre Buchstaben im Gitter markierst.
